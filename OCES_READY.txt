TROUBLESHOOTING
──────────────────────────────────────────────────────────────────────────────

Issue: "ModuleNotFoundError: No module named 'config'"
Solution:
  • Ensure backend/config/ folder exists
  • Verify __init__.py is in the folder
  • Restart Python/terminal

Issue: "KeyError: OBS_VALUE"
Solution:
  • Check your CSV has exactly "OBS_VALUE" column
  • Check spelling and case
  • Verify first row is headers

Issue: "No data showing in browser"
Solution:
  • Run: python backend/test_backend.py
  • Check terminal output for errors
  • Verify data folder has oces_data.csv
  • Check CSV file is readable/not corrupted

Issue: "Charts appear but with wrong data"
Solution:
  • Check that regions/products match your CSV
  • Verify column mappings in column_mapping.py
  • Ensure OBS_VALUE has numeric data
