HOW THE SYSTEM HANDLES YOUR DATA
──────────────────────────────────────────────────────────────────────────────

Step 1: Load CSV
  → Reads oces_data.csv from backend/data/
  → Auto-detects OCES format by checking for OBS_VALUE column

Step 2: Normalize Columns
  → Maps your column names to internal system names:
    - REF_AREA → region
    - COMMODITY → product
    - TIME_PERIOD → year
    - OBS_VALUE → value

Step 3: Type Conversion
  → Converts TIME_PERIOD to numeric (years)
  → Converts OBS_VALUE to numeric (floats for values)

Step 4: Filter Invalid Data
  → Removes rows with missing values or year/value
  → Keeps only clean, usable data

Step 5: Analysis Ready
  → System can now group by region, product, year
  → Can filter, aggregate, and visualize

TROUBLESHOOTING
──────────────────────────────────────────────────────────────────────────────

Problem: "Column not found error"
  → Check column name matches exactly (case-sensitive)
  → Verify CSV has the column in first row
  → Check for leading/trailing spaces

Problem: "No data appears"
  → Run: python backend/test_backend.py
  → Check for errors in terminal
  → Ensure OBS_VALUE column has numeric values

Problem: "Charts not showing"
  → Check browser console (F12) for errors
  → Check backend terminal for red text
  → Verify data rows with non-empty OBS_VALUE

Problem: "Incorrect grouping/filtering"
  → Check that region/product values match your CSV
  → Verify column names in queries match data
  → Ensure TIME_PERIOD is numeric
