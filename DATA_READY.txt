WHEN YOU UPLOAD YOUR DATA
─────────────────────────────────────────────────────────────────────────────

Steps to follow:

1. Prepare your CSV file
   → Ensure proper CSV format
   → Check headers are clear
   → Verify data consistency

2. Save as: oces_data.csv
   → Keep exact filename

   → Keep oecd_agricultural_data.csv as backup

4. Restart backend
   → Stop backend server (Ctrl+C)
   → Run: python -m uvicorn backend.api.main:app --host 0.0.0.0 --port 8000 --reload
   → Wait for "Application startup complete"

5. Test in browser
   → http://localhost:3000
   → Try queries with your column names
   → See charts with your data
